
# 🥬 SayurSegar — Fresh from Local Farmers

SayurSegar is a simple and responsive website developed as part of a 2025 KKN project to support local farmers in Desa Girimulya. The website provides information about fresh vegetables, product prices, and direct communication channels for customers.

## 🌱 About the Project

SayurSegar aims to make information about locally available vegetables easier to access while helping connect local farmers with potential customers through a simple digital platform.

## ✨ Features

- **Home Page** — Introduces SayurSegar and highlights selected vegetables.
- **Product Catalog** — Displays vegetable images, descriptions, and example prices.
- **Contact Page** — Provides contact information and location details.
- **WhatsApp Integration** — Allows customers to ask about products and ordering.
- **Google Maps** — Helps visitors explore the project location.
- **Responsive Design** — Designed to provide a usable experience across desktop and mobile screens.

## 🥕 Featured Products

The website showcases several vegetables, including:

- Cabbage
- Carrots
- Tomatoes
- Mustard greens
- Potatoes
- Spinach

Product prices displayed on the website are examples and should be confirmed before ordering.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/RifqiAiniWahdaniyatillahi/sayursegar-website.git
   ```

2. Open the project folder:

   ```bash
   cd sayursegar-website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No backend or package installation is required for the current static website.
